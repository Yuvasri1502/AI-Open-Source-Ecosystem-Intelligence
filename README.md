AI Open-Source Ecosystem & Developer Tool Intelligence

An interactive Microsoft Power BI project that explores the GitHub AI open-source ecosystem, technology adoption, developer tools, repository popularity, growth, and project health.

🎯 Project Objectives

* Understand the GitHub AI open-source ecosystem.
* Identify popular AI repositories.
* Analyze AI technology and developer tool adoption.
* Compare repository popularity and growth.
* Evaluate project health and maintenance activity.
* Discover patterns that support data-driven decisions.

🛠️ Tools & Technologies

* Microsoft Power BI
* Power Query
* DAX
* Data Cleaning and Transformation
* Data Modeling
* Data Visualization

📊 Project Dashboards

1. AI Ecosystem Overview

Provides a high-level overview of the AI repository ecosystem using key performance indicators and visualizations.

2. AI Technology & Developer Tools

Explores the adoption of AI technologies and developer tools, including RAG, AI agents, fine-tuning, vector databases, MCP, and frameworks.

3. Popularity, Growth & Project Health

Analyzes repository popularity, stars, forks, growth indicators, and project maintenance health.
